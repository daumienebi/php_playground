Difference between get and post (_$GET and $_POST):

Get isn't the best when it comes to sensitive data, the data (array of variables) sent is passed to the script using the url query params. The post method on the other hand passes the data to the script using the HTTP post method It's also important to note that the $_GET method also has a limitation of about 2000 caracteres.
